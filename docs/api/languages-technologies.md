# Языки и технологии

Два **списка с порядком**: языки, которыми владеет человек, и основной стэк резюме. Порядок записей — порядок на странице.
Фронтенд: `createItem` / `updateItem` / `deleteItem` (`languages`, `technologies`) → вкладки «Языки» и «Стэк». Форма не хранит `id`, поэтому фронтенд сопоставляет записи формы и сервера **по индексу**: i-я запись формы обновляет i-ю серверную, лишние создаются или удаляются с конца.

## Общая схема ручек

`{list}` — `languages` или `technologies`.

| Метод и путь | Что делает | Ответ |
|---|---|---|
| `POST /lk/resume/:resumeId/{list}` | добавить в конец списка | `201 {"id"}` |
| `GET /lk/resume/:resumeId/{list}` | список по порядку | `200 [ … ]` |
| `GET /lk/resume/:resumeId/{list}/:itemId` | одна запись | `200`; `404` |
| `PUT /lk/resume/:resumeId/{list}/:itemId` | заменить запись (позиция не меняется) | `204`; `404` |
| `DELETE /lk/resume/:resumeId/{list}/:itemId` | удалить | `204`; `404` |
| `PUT /lk/resume/:resumeId/{list}/order` | переставить | `204` |

Фронтенд использует первые ручки; `GET` по одной записи и `order` пока не вызывает.

## Языки (`/languages`)

| Поле | Тип | Обяз. | Ограничения | Дефолт при создании |
|---|---|---|---|---|
| `language` | string | да | `ru en fr de kz zh es`; **уникален в пределах резюме** (повтор → `409`) | — |
| `grade` | string | нет | `A1 A2 B1 B2 C1 C2` | отсутствует |

Позиция (`position`, с нуля) назначается сервером: новая запись получает `максимум + 1` (первая — `0`). В теле `position` слать нельзя (`400`). В ответах `GET` поле `position` есть.

## Технологии (`/technologies`)

| Поле | Тип | Обяз. | Ограничения | Дефолт при создании |
|---|---|---|---|---|
| `name` | string | да | непустое; **свободный текст**, дубли по имени допустимы | — |
| `grade` | string | нет | `intern junior middle senior` | отсутствует |

Позиция назначается так же, как у языков. Фронтенд поле `grade` не редактирует и не отправляет (сохраняется только `name`).

## Перестановка (`PUT …/{list}/order`)

```json
{ "ids": ["<uuid>", "<uuid>", "<uuid>"] }
```

| Поле | Тип | Обяз. | Ограничения |
|---|---|---|---|
| `ids` | uuid[] | да | **полный** набор id записей списка в новом порядке: без повторов, без чужих, длина равна текущей, не пусто; иначе `400` |

Ответ `204`.
