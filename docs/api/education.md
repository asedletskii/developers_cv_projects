# Образование и курсы

Два независимых списка. Фронтенд: вкладки «Образование» и «Курсы»; записи сопоставляются **по `id`** (новые — `POST`, известные — `PUT`, пропавшие — `DELETE`).

Схема ручек одинакова (`{list}` — `educations` или `courses`, `{itemId}` — `educationId`/`courseId`):

| Метод и путь | Что делает | Ответ |
|---|---|---|
| `POST /lk/resume/:resumeId/{list}` | добавить в конец | `201 {"id"}` |
| `GET /lk/resume/:resumeId/{list}` | список | `200 [ … ]` |
| `GET /lk/resume/:resumeId/{list}/:itemId` | одна запись | `200`; `404` |
| `PUT /lk/resume/:resumeId/{list}/:itemId` | заменить запись | `204`; `404` |
| `DELETE /lk/resume/:resumeId/{list}/:itemId` | удалить | `204`; `404` |

Порядок — по времени создания, переставить нельзя.

## Образование (`/education`)

| Поле | Тип | Обяз. | Ограничения | Дефолт при создании |
|---|---|---|---|---|
| `location` | string | да | непустое (город) | — |
| `university` | string | да | непустое | — |
| `grade` | integer | да | `0`–`6`: 0 среднее, 1 бакалавриат, 2 специалитет, 3 магистратура, 4 аспирантура, 5 кандидат наук, 6 доктор наук | — |
| `programName` | string | да | непустое | — |
| `profileName` | string | нет | наименование профиля | отсутствует |
| `faculty` | string | да | непустое | — |
| `course` | integer | нет | не меньше 1 (для ещё не выпустившихся) | отсутствует |
| `endDate` | string | нет | год `YYYY` | отсутствует |

Между `course` и `endDate` бэкенд связи не проверяет: можно задать оба или ни одного.

## Курсы (`/courses`)

| Поле | Тип | Обяз. | Ограничения | Дефолт при создании |
|---|---|---|---|---|
| `name` | string | да | непустое | — |
| `organization` | string | да | непустое (организация или платформа) | — |
| `endDate` | string | да | `YYYY-MM` | — |
| `hours` | integer | нет | больше 0 | отсутствует |
| `certificateLink` | string | нет | `http`/`https`-ссылка | отсутствует |

Ответы `GET` содержат те же поля плюс `id` и `resumeId`.
