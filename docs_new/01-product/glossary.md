# Глоссарий

| Термин | Определение | В коде |
|---|---|---|
| **Пользователь** | Учётная запись кандидата. Сейчас заводится миграцией | `users` |
| **Профиль пользователя** | Имя, фамилия, отчество, должность, город (на ru и en) и фото владельца кабинета. Не относится к конкретному резюме; служит источником для кнопки «Как в профиле» | `user_profiles`, `user_profile_localizations`, `GET/PUT /lk/profile` |
| **Кабинет (ЛК)** | Интерфейс кандидата: профиль, список резюме, редактор, ссылки, аналитика | `/cv/lk/:userId` |
| **Резюме** | Контейнер с названием, языком, статусом и версией; владеет всеми секциями | `resumes`, агрегат `domain.Resume` |
| **Язык резюме** | Язык, на котором написано резюме: `ru en fr de kz zh es`. Задаётся при создании, не меняется | `resumes.language` |
| **Язык интерфейса** | Язык подписей сайта: `ru` или `en`. Выбирает посетитель, не зависит от языка резюме | `localStorage.language` |
| **Статус резюме** | `draft` (черновик) → `opened` (опубликовано) ↔ `closed` (скрыто). Публичная страница работает только для `opened` | `resumes.status` |
| **Версия резюме** | Целое число, растёт на 1 при каждом изменении резюме или любой его секции. Используется для оптимистичной блокировки | `resumes.version` |
| **Конфликт версий** | Клиент прислал изменение с устаревшей версией — кто-то уже сохранил резюме в другой вкладке. Ответ `412 Precondition Failed` | `ErrConcurrencyConflict` |
| **Секция** | Смысловой блок резюме: обзор, профиль, контакты, навыки, языки, стек, опыт, образование, курсы, активности, проекты | `/lk/resume/:id/<section>` |
| **Секция-одиночка** | Секция с одной записью на резюме: обзор, профиль, контакты, навыки | `SingletonSection` на фронте |
| **Секция-список** | Секция из упорядоченного списка записей: языки, стек, опыт, образование, курсы, активности, проекты | `ListSection` на фронте |
| **Обзор (overview)** | Оформление страницы: цвета, приветствие, доступность, ссылка на файл резюме, порядок и видимость секций | `resume_overviews` |
| **Секция страницы** | Блок публичной страницы: `about techStack experience skills education courses projects activities contacts`. Порядок и видимость задаёт обзор | `SectionId` |
| **Доступность (availability)** | Готовность к предложениям: `open` (открыт), `considering` (рассматриваю), `busy` (не ищу), с датой «доступен с» и комментарием | `overview.availability` |
| **Скрытый контакт** | Контакт, значение которого не попадает в публичный ответ и выдаётся отдельным запросом по клику «Показать» | `hiddenContacts`, `POST /cv/:linkId/contact-views` |
| **Раскрытие контакта** | Запрос посетителя на значение скрытого контакта. Фиксируется как событие аналитики `contact_view` | `resume_link_events` |
| **Ссылка (именованная ссылка)** | Собственный адрес резюме для конкретного адресата: `https://<домен>/cv/<linkId>`. У неё есть название, статус и счётчики | `resume_links` |
| **Статус ссылки** | `active` — открывается; `inactive` — отвечает `404`, как несуществующая | `resume_links.status` |
| **Публичная страница** | Страница резюме для посетителя по ссылке | `CurriculumVitaeScreen` |
| **Предпросмотр** | Страница резюме глазами посетителя, открытая из кабинета. Не требует публикации и не считается в аналитике | `/cv/lk/:userId/:cvId/preview`, `LkResumeScreen` |
| **Публичная проекция** | JSON резюме для посетителя: без статуса, версии, служебных id и значений скрытых контактов | `queries.ToPublic` |
| **Заполненность** | Доля заполненных секций резюме (10 пунктов), показывается на «Главной» резюме в кабинете | `getResumeChecklist` |
| **Фильтр технологий** | Режим публичной страницы: выбранная технология подсвечивает места работы и проекты, где она использовалась | `TechnologyFilterProvider` |
| **Визит, открытие, прочтение, посетитель** | Термины аналитики | [docs/analytics](../../docs/analytics/README.md#термины) |
| **Outbox** | Таблица исходящих уведомлений, заполняемая в той же транзакции, что и событие | план, `analytics_outbox` |
