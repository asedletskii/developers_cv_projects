Категории — по модели качества ISO/IEC 25010, адаптированной под продукт.

| Файл | Категории | Коды |
|---|---|---|
| [performance-reliability.md](performance-reliability.md) | Производительность, надёжность и доступность, восстановление | `NFR-PERF`, `NFR-REL` |
| [security-privacy.md](security-privacy.md) | Безопасность, персональные данные | `NFR-SEC`, `NFR-PRV` |
| [observability.md](observability.md) | Логи, метрики, трассировка, алерты | `NFR-OBS` |
| [ux-compatibility.md](ux-compatibility.md) | Адаптивность, совместимость, доступность (a11y), локализация | `NFR-UX` |
| [maintainability.md](maintainability.md) | Архитектура, тесты, CI/CD, зависимости, документация | `NFR-MNT` |

## Формат

| Колонка | Что писать |
|---|---|
| **ID** | `NFR-<КАТ>-<NN>` |
| **Требование** | Проверяемое утверждение |
| **Метрика и цель** | Что измеряем и какое значение считается выполнением |
| **Проверка** | Чем подтверждается: тест, CI-шаг, дашборд, ручная проверка, аудит |
| **Сейчас** | Фактическое состояние в `main` |
| **Статус** | Реализовано / Частично / План |

Приоритет у всех NFR — **Must**, если не указано иное: нефункциональные требования здесь — это минимальная планка качества, а не пожелания.
