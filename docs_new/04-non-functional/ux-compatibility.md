# Интерфейс, совместимость, доступность (NFR-UX)

| ID | Требование | Метрика и цель | Проверка | Сейчас | Статус |
|---|---|---|---|---|---|
| NFR-UX-01 | Адаптивная вёрстка | Публичная страница и кабинет без горизонтальной прокрутки и перекрытий на ширине **360–2560 px**; области нажатия на сенсорных экранах ≥ 40×40 px | Визуальные тесты Playwright на 360, 768, 1280, 1920 px | Вёрстка адаптивная; визуальных тестов нет | Частично |
| NFR-UX-02 | Поддержка браузеров | Последние 2 версии Chrome, Safari (macOS, iOS), Firefox, Edge, Яндекс Браузера; Safari iOS ≥ 16. Сценарии: открыть резюме, фильтр, раскрытие контакта, печать; в кабинете — создать и опубликовать резюме | Ручной смоук перед релизом; `browserslist` в сборке | Систематически не проверяется | Частично |
| NFR-UX-03 | Локализация интерфейса | Все строки интерфейса — через словари `ru` и `en`; ключи словарей совпадают; даты и числа — через `dayjs`/`Intl` в локали интерфейса; язык определяется по сохранённому выбору, затем по языку браузера | Jest-тест на совпадение ключей словарей | Словари и определение языка — есть; автотеста совпадения ключей нет | Частично |
| NFR-UX-04 | Доступность (a11y) | **WCAG 2.1 AA** для публичной страницы: контраст текста ≥ 4.5:1 в обеих темах, видимый фокус, работа с клавиатуры, доступные имена у кнопок-иконок, семантические заголовки; Lighthouse Accessibility ≥ 95 | axe-core в e2e; ручная проверка со скринридером (VoiceOver, NVDA) раз в релиз | Частично: `aria-label` у кнопок-иконок, `role="status"` у плашки фильтра, Escape снимает фильтр; аудита не было; контраст пользовательских цветов не проверяется | Частично |
| NFR-UX-05 | Уважение системных настроек | `prefers-color-scheme` — тема по умолчанию; `prefers-reduced-motion: reduce` — анимации отключены; эффекты наведения — только при `hover: hover` | Ручная проверка с эмуляцией в DevTools | Как в требовании | Реализовано |
| NFR-UX-06 | Печатная версия | Печать в светлой теме, без интерактивных элементов; текст не обрезается; секции не рвутся посередине заголовка | Ручная проверка в Chrome и Safari | Как в требовании (разрывы страниц — проверить) | Реализовано |
| NFR-UX-07 | Обратная связь на действия | Любое действие кабинета даёт видимую реакцию ≤ 100 мс (индикатор, блокировка кнопки); результат сохранения — тост или статус «Сохранено»; ошибка — человекочитаемый текст без технических деталей | Ручная проверка | Так | Реализовано |
| NFR-UX-08 | Понятные ошибки публичной страницы | Экран ошибки объясняет, что делать; для 5xx — код и ID запроса для обращения | Ручная проверка | Так | Реализовано |
