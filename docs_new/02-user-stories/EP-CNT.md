# EP-CNT. Контакты и защита от сбора

**Цель эпика:** рекрутеру легко связаться с кандидатом, а парсеру — трудно собрать контакты.

**Метрики:** доля прочтений с раскрытием или копированием контакта; число раскрытий с одного IP за сутки (аномалии).

---

### US-CNT-01. Связаться в один клик

**Must** · **Реализовано** · P2 Рекрутер

Как рекрутер, я хочу написать кандидату в Telegram, на почту или позвонить одним нажатием либо скопировать контакт, чтобы не перепечатывать его вручную.

```gherkin
Сценарий: Открытый Telegram
  Дано Telegram кандидата не скрыт
  Когда рекрутер нажимает «Telegram»
  Тогда открывается t.me/<username>

Сценарий: Копирование почты
  Когда рекрутер нажимает «Скопировать» у почты
  Тогда адрес копируется в буфер обмена и показано подтверждение

Сценарий: Звонок с телефона
  Когда рекрутер нажимает «Позвонить» на телефоне
  Тогда открывается набор номера (tel:)
```

**Требования:** FR-CNT-020, FR-CNT-021.

---

### US-CNT-02. Скрыть контакты от парсеров

**Must** · **Реализовано** · P1 Кандидат

Как кандидат, я хочу, чтобы скрытые контакты не попадали в код страницы и ответ API, чтобы их не собрали боты для спама.

```gherkin
Сценарий: Значение не утекает
  Дано почта кандидата скрыта
  Когда клиент запрашивает GET /api/v1/cv/<linkId>
  Тогда в ответе нет адреса почты ни в каком поле
  И в hiddenContacts указано «email», чтобы интерфейс показал кнопку «Показать почту»

Сценарий: Статус и версия не утекают
  Тогда в публичном ответе нет статуса, версии резюме и идентификатора пользователя
```

**Требования:** FR-CNT-001 – FR-CNT-004.

---

### US-CNT-03. Раскрыть скрытый контакт

**Must** · **Реализовано** · P2 Рекрутер

Как рекрутер, я хочу по клику увидеть скрытый контакт, чтобы связаться с кандидатом.

```gherkin
Сценарий: Раскрытие
  Когда рекрутер нажимает «Показать почту»
  Тогда кнопка заменяется адресом почты с действиями «Написать» и «Скопировать»
  И раскрытие учитывается в статистике ссылки

Сценарий: Контакт не скрыт
  Когда клиент API запрашивает раскрытие открытого контакта
  Тогда ответ 409 «Contact is not hidden»

Сценарий: Ссылка выключена
  Когда ссылка неактивна или резюме не опубликовано
  Тогда ответ 404, значение не выдаётся
```

**Требования:** FR-CNT-010 – FR-CNT-014, FR-ANL-001.

### US-CNT-04. Проверка на бота при раскрытии

**Should** · **План** · P1 Кандидат

Как кандидат, я хочу, чтобы массовые запросы на раскрытие контактов блокировались, чтобы даже скрытые контакты нельзя было собрать скриптом.

```gherkin
Сценарий: Массовое раскрытие
  Дано с одного IP за 10 минут пришло больше 20 запросов на раскрытие по разным ссылкам
  Когда приходит следующий запрос
  Тогда он отклоняется 429, значение не выдаётся
  И событие попадает в журнал безопасности

Сценарий: Подозрительный клиент
  Дано запрос классифицирован как бот
  Тогда раскрытие требует прохождения невидимой проверки (например, SmartCaptcha)
  И обычный посетитель в браузере её не замечает
```

**Требования:** FR-CNT-015, FR-CNT-016, NFR-SEC-06.

**Комментарий.** Из TODO: «Защита от парсеров в разделе контактов, отдача полей после валидации на бэке». Отдача после валидации сделана (US-CNT-02, US-CNT-03), проверка на бота — нет.

### US-CNT-05. Свой текст блока контактов

**Could** · **Реализовано** · P1 Кандидат

Как кандидат, я хочу задать свой заголовок и подзаголовок блока контактов или скрыть их, чтобы призыв звучал в моём стиле.

```gherkin
Сценарий: Свой заголовок
  Когда кандидат задаёт заголовок «Обсудим проект?»
  Тогда блок контактов показывает его вместо «Давайте работать вместе»

Сценарий: Скрыть подзаголовок
  Когда подзаголовок задан пустой строкой
  Тогда подзаголовок не выводится

Сценарий: Не задан
  Тогда выводятся тексты по умолчанию на языке интерфейса
```

**Требования:** FR-EDT-024.
