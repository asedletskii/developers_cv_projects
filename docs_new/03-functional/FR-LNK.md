# FR-LNK. Именованные ссылки

Истории: [EP-LNK](../02-user-stories/EP-LNK.md).

## Модель

```
resume_links (id uuid PK, resume_id → resumes, name, status ∈ {active, inactive}, version, created_at, updated_at)
  UNIQUE (resume_id, name), name 1..128 символов
resume_link_events (id, link_id → resume_links, event_type ∈ {view, contact_view}, occurred_at)
```

Адрес ссылки: `https://<домен>/cv/<linkId>`. Идентификатор ссылки — UUIDv4, генерируется сервером; по нему нельзя вычислить ни резюме, ни пользователя.

```
          deactivate
  active ───────────▶ inactive
    ▲                    │
    └────────────────────┘
          activate
```

## Требования

### Создание и список

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-LNK-001 | `POST /lk/link` с телом `{ resumeId, name }` должен создавать активную ссылку с версией `1` и отвечать `201 {"id"}` | Must | Реализовано | |
| FR-LNK-002 | `name` обрезается по краям и должен быть длиной 1–128 символов. Иначе `400 "Invalid link name"` | Must | Реализовано | |
| FR-LNK-003 | Название уникально в пределах резюме. Повтор — `409 "Resume link already exists"` | Must | Реализовано | `UNIQUE (resume_id, name)` |
| FR-LNK-004 | Ссылки доступны только владельцу резюме. Чужое резюме или ссылка — `404` | Must | Реализовано | |
| FR-LNK-005 | У резюме не больше 50 ссылок. Превышение — `409 "Resume link limit exceeded"` | Must | Реализовано | `MaxResumeLinksPerResume` |
| FR-LNK-006 | Ссылку можно создать для резюме в любом статусе; открываться посетителю она будет только для опубликованного | Must | Реализовано | |
| FR-LNK-007 | `GET /lk/links?resumeId=<uuid>` возвращает ссылки резюме `{ id, name, status, version, createdAt, updatedAt }`. Невалидный `resumeId` — `400` | Must | Реализовано | |

### Изменение

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-LNK-010 | `PUT /lk/link/:linkId` с телом `{ version, name }` должен переименовывать ссылку по правилам FR-LNK-002, FR-LNK-003 и отвечать `204`. Адрес не меняется | Should | Частично | Фронт вызывает `PUT /lk/link/:linkId` с `{ name }` без версии; на бэке маршрута нет — `404` ([GAP-02](../06-gaps-and-risks.md#расхождения)) |
| FR-LNK-011 | `PUT /lk/link/:linkId/status` с телом `{ status, version }` (`active` или `inactive`) должен менять статус и отвечать `204`. Неизвестный статус или `version < 1` — `400` | Must | Реализовано | |
| FR-LNK-012 | Устаревшая версия ссылки — `412 PRECONDITION_FAILED "Resume link was modified"`. После любого изменения интерфейс перечитывает список, а не правит его локально | Must | Реализовано | `useResumeLinks` |
| FR-LNK-013 | `DELETE /lk/link/:linkId` удаляет ссылку вместе с событиями и отвечает `204`. Интерфейс запрашивает подтверждение «Удалить ссылку «…»?» | Should | Реализовано | |
| FR-LNK-014 | Выключенная или удалённая ссылка отвечает посетителю так же, как несуществующая ([FR-PUB-003](FR-PUB.md)) | Must | Реализовано | |

### Интерфейс

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-LNK-020 | Если у резюме нет ссылок, «Главная» и вкладка «Ссылки» показывают призыв «Поделитесь резюме» с кнопкой «Создать ссылку», создающей ссылку «Публичная ссылка» | Must | Реализовано | `CreateLinkPrompt`. Прямой адрес резюме не показывается |

| FR-LNK-022 | Ошибка загрузки списка — «Не удалось загрузить ссылки» с кнопкой «Повторить» | Should | Реализовано | |
