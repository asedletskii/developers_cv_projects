# FR-EDT. Редактор и секции резюме

Истории: [EP-EDT](../02-user-stories/EP-EDT.md). Оформление (секция `overview`) — в [FR-DSG](FR-DSG.md), контакты — здесь и в [FR-CNT](FR-CNT.md).

## Общие правила сохранения секций

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-EDT-001 | Каждая секция сохраняется запросом `PUT /lk/resume/:resumeId/<секция>` с полем `version` и полностью заменяет прежнее содержимое секции. Ответ `204` | Must | Реализовано | Одиночки: `profile`, `contacts`, `skills`, `overview`. Списки: `languages`, `technologies`, `experiences`, `educations`, `courses`, `activities`, `projects` |
| FR-EDT-002 | Секция-одиночка создаётся первым `PUT`; отдельного `POST` и удаления нет. Пока секция не создана, её поле отсутствует в `GET /lk/resume/:resumeId` | Must | Реализовано | |
| FR-EDT-003 | Тело секции-списка — `{ version, items: [...] }`. Порядок `items` — порядок записей на странице | Must | Реализовано | |
| FR-EDT-004 | Запись списка без `id` создаётся с новым серверным `id`. Запись с `id` существующей записи этой секции сохраняет идентичность. Запись с чужим или неизвестным `id`, а также повтор `id` в одном запросе — `400`. Записи, которых нет в `items`, удаляются | Must | Реализовано | `domain.Resume.Replace*` |
| FR-EDT-005 | Ошибки валидации секции — `400 "Invalid request"`; ни одна запись секции при этом не меняется (транзакция целиком) | Must | Реализовано | `transaction_rollback_test.go`. Кандидат на улучшение: указывать в ответе поле и причину |
| FR-EDT-006 | Интерфейс сохраняет только текущую вкладку редактора, отправляя клиентский `id` только для записей, пришедших с сервера | Must | Реализовано | `buildSectionRequest` |

## Профиль резюме (`profile`) — «Обо мне»

| Поле | Тип | Обяз. | Правило |

| `relocation` | boolean | нет | по умолчанию `false` |

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-EDT-010 | Сервер должен принимать профиль резюме с полями из таблицы и отклонять нарушение любого правила ответом `400` | Must | Реализовано | |

## Контакты (`contacts`)

| Поле | Тип | Обяз. | Правило |
|---|---|---|---|
| `phone` | string | нет | свободная строка |
| `telegram` | string | нет | ведущий `@` отбрасывается; только `a-z A-Z 0-9 _` |
| `email` | string | нет | корректный адрес без отображаемого имени |
| `hiddenContacts` | string[] | нет | `phone telegram email`, без повторов, только заполненные |
| `contactsText` | object | нет | если задан — хотя бы одно из `title`, `subtitle` |

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-EDT-020 | Должен быть задан хотя бы один из `phone`, `telegram`, `email`. Иначе `400` | Must | Реализовано | Дублируется `CHECK resume_contacts_presence_check` |
| FR-EDT-021 | Telegram хранится без ведущего `@`; символы вне `a-z A-Z 0-9 _` — `400` | Must | Реализовано | |
| FR-EDT-022 | Email должен разбираться как адрес `local@domain` без отображаемого имени. Иначе `400` | Must | Реализовано | `net/mail` |
| FR-EDT-023 | `hiddenContacts` может содержать только заполненные контакты, без повторов. Иначе `400` | Must | Реализовано | «hidden contact is not filled» |
| FR-EDT-024 | `contactsText.title` и `subtitle`: отсутствие поля — текст по умолчанию на языке интерфейса; пустая строка — строка скрыта; `{}` — `400` | Could | Реализовано | |
| FR-EDT-025 | Длина Telegram-имени должна быть 5–32 символа, как требует Telegram | Could | План | Сейчас длина не проверяется |

## Языки (`languages`)

Элемент: `{ id?, language, grade?, position }`.

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-EDT-040 | `language` — из справочника языков, `grade` — из CEFR (`A1`–`C2`) или отсутствует | Should | Реализовано | |
| FR-EDT-041 | Язык не может повторяться в пределах резюме. Повтор — `400` | Should | Реализовано | Дублируется `UNIQUE (resume_id, language)` |
| FR-EDT-042 | `position` должен образовывать непрерывный ряд `0…n-1` без повторов. Иначе `400` | Should | Реализовано | «positions must be contiguous» |
| FR-EDT-043 | Интерфейс не даёт выбрать уже добавленный язык и позволяет переставлять записи кнопками «Переместить выше/ниже» | Should | Реализовано | |
