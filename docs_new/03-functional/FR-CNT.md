# FR-CNT. Контакты и защита от сбора

Истории: [EP-CNT](../02-user-stories/EP-CNT.md). Правила заполнения контактов — [FR-EDT-020 – FR-EDT-025](FR-EDT.md#контакты-contacts).

## Модель угроз

| Угроза | Атакующий | Защита | Статус |
|---|---|---|---|
| Сбор контактов из HTML/JSON страницы | Парсер, краулер | Скрытые контакты не попадают в публичную проекцию (FR-CNT-003) | Реализовано |
| Массовое раскрытие через ручку `contact-views` | Скрипт, знающий ссылки | Рейт-лимит общий (FR-API-020); отдельный лимит и проверка на бота (FR-CNT-015, FR-CNT-016) | Частично |
| Перебор адресов ссылок | Скрипт | UUIDv4 в адресе; одинаковый `404` для всех причин (FR-PUB-003) | Реализовано |
| Сбор открытых (не скрытых) контактов | Парсер | Не защищаются по решению кандидата; интерфейс рекомендует скрывать почту и телефон (FR-CNT-005) | План |

## Требования

### Публичная выдача

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-CNT-001 | Кандидат может отметить любой заполненный контакт как скрытый ([FR-EDT-023](FR-EDT.md)) | Must | Реализовано | |
| FR-CNT-002 | Публичная проекция содержит `hiddenContacts` — список ключей скрытых контактов, чтобы интерфейс показал кнопки раскрытия | Must | Реализовано | |
| FR-CNT-003 | Значение скрытого контакта не должно присутствовать в публичной проекции ни в каком поле | Must | Реализовано | `redactHiddenContacts`, тест `TestPublicProjectionDoesNotContainHiddenValues` |
| FR-CNT-004 | Предпросмотр в кабинете показывает скрытые контакты так же, как посетителю | Should | Реализовано | |
| FR-CNT-005 | Редактор контактов по умолчанию предлагает скрывать почту и телефон | Could | План | |

### Раскрытие

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-CNT-010 | `POST /api/v1/cv/:linkId/contact-views` с телом `{ contact }` должен возвращать `200 { contact, value }` для скрытого заполненного контакта | Must | Реализовано | |
| FR-CNT-011 | Условия раскрытия — те же, что у публичной проекции: ссылка существует и активна, резюме в статусе `opened`. Иначе `404 "Resume not found"` | Must | Реализовано | |
| FR-CNT-012 | Незаполненный контакт — `404 "Contact not found"`; открытый (не скрытый) — `409 "Contact is not hidden"`; неизвестный ключ — `400` | Must | Реализовано | |
| FR-CNT-013 | Ответ раскрытия — `Cache-Control: no-store` | Must | Реализовано | |
| FR-CNT-014 | Каждое успешное раскрытие регистрирует событие `contact_view` ссылки ([FR-ANL-001](FR-ANL.md)) | Must | Реализовано | |
| FR-CNT-015 | Ручка раскрытия должна иметь отдельный лимит: не больше 20 раскрытий с одного IP за 10 минут по всем ссылкам; превышение — `429`, запись в журнал безопасности | Should | План | Сейчас действует только общий лимит 50 rps |
| FR-CNT-016 | Для клиентов, классифицированных как боты, раскрытие должно требовать прохождения невидимой проверки (например, Yandex SmartCaptcha) | Should | План | TODO: «защита от парсеров» |
