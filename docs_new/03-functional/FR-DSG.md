# FR-DSG. Оформление и структура страницы

Истории: [EP-DSG](../02-user-stories/EP-DSG.md). Всё хранится в секции «Обзор» и сохраняется одним запросом `PUT /lk/resume/:resumeId/overview`.

## Контракт

```json
{
  "version": 7,
  "theme": { "primary": "#E8785A", "secondary": "#428BF9" },
  "greeting": { "first": "Привет!", "second": "Меня зовут", "secondHighlight": "Антон", "third": "Frontend-разработчик" },
  "availability": { "status": "open", "from": "2026-10-01", "note": "Ищу роль Senior" },
  "resumeLink": "https://example.com/cv.pdf",
  "sections": [ { "id": "about", "enabled": true, "collapsed": false } ]
}
```

| Поле | Обяз. | Правило |
|---|---|---|
| `theme` | нет | если задан — хотя бы один цвет; цвета `#RGB` / `#RRGGBB` |
| `greeting` | да | четыре строки, каждая может быть пустой |
| `availability` | нет | если задан — `status` из справочника; `from` — `YYYY-MM-DD`; `note` — текст |
| `resumeLink` | нет | `http(s)`-ссылка |
| `sections` | нет | `id` из справочника секций, без повторов; допустим любой поднабор |

## Требования

### Цвета

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-DSG-001 | Кандидат может задать основной и дополнительный цвет; некорректный цвет — `400` | Could | Реализовано | `valueobjects/theme.go` |
| FR-DSG-002 | Публичная страница строит акцентную тему из заданных цветов для светлого и тёмного режима; без заданных цветов — цвета по умолчанию | Could | Реализовано | `createAccentTheme` |
| FR-DSG-003 | Редактор показывает предпросмотр цветов на примере заголовка и кнопки «Связаться» в светлой и тёмной теме | Could | Реализовано | `ThemePreviewDialog` |
| FR-DSG-004 | Редактор должен предупреждать, если контраст акцентного цвета с фоном ниже 4.5:1 в одной из тем | Could | План | Связано с NFR-UX-04 |

### Первый экран

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-DSG-010 | Приветствие — три строки, у второй есть выделенная часть. Пустые строки не выводятся | Should | Реализовано | `HeroSection/Greeting` |
| FR-DSG-011 | Доступность выводится как «Открыт к предложениям / Рассматриваю предложения / Сейчас не ищу» с датой «с D MMMM YYYY» и комментарием; без доступности блок скрыт | Should | Реализовано | `HeroSection/Availability` |
| FR-DSG-012 | Если задана ссылка на файл резюме, страница показывает кнопку скачивания ([FR-PUB-040](FR-PUB.md)) | Should | Реализовано | |

### Секции

| ID | Требование | Приоритет | Статус | Комментарий |
|---|---|---|---|---|
| FR-DSG-020 | Порядок элементов `sections` задаёт порядок секций на странице и в навигации; `enabled: false` скрывает секцию | Should | Реализовано | |
| FR-DSG-021 | Пустой `sections` означает «все секции в порядке по умолчанию»: `about, techStack, experience, skills, education, courses, projects, activities, contacts` | Should | Реализовано | Правило фронта, бэк не подставляет |
| FR-DSG-022 | Секция `about` всегда первая и включена: редактор не даёт её сдвинуть или выключить, публичная страница исправляет порядок, даже если пришло иначе | Should | Реализовано | `withPinnedAbout` |
| FR-DSG-023 | `collapsed: true` — секция открывается свёрнутой (только для секций, которые фронт умеет сворачивать) | Could | Реализовано | `SectionCollapseProvider` |
| FR-DSG-024 | Повтор или неизвестный `id` секции — `400` | Should | Реализовано | |

|---|---|---|---|---|
